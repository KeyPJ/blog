# 湖北城乡养老缴费怎么缴？当年/补缴/资助/二次缴费一次讲透

> 很多群友经常问城乡养老缴费怎么缴?其实之前都有汇总的,再汇总一下吧.

## 一、当年正常缴费：选好档次，政府给补贴

参保人每年按时缴纳城乡居民养老保险，在鄂汇办或者电子税务局缴费时，界面一般提供三类选项：**当年缴费、补缴(无未缴年费时不显示)、核定单缴费**。其中：

- **当年缴费（正常缴费）**：缴的是本年度保费，到账后政府同步给予**缴费补贴**，相当于"自己存一笔、政府再补一笔"，最划算；
- **补缴 / 核定单缴费**：属于补齐年限、子女资助、二次提档等情形。

所以，能当年缴就尽量当年缴，补贴别错过。

（注："鄂汇办"指鄂汇办 APP，或支付宝里的「鄂汇办」小程序。"电子税务局"指电子税务局app或网页）

**湖北省级城乡居民基本养老保险缴费档次与政府补贴**

| 档次 | 年缴费标准                      | 政府补贴 / 年 |
| -- | -------------------------- | -------- |
| 一档 | 300 元、400 元                | 45 元     |
| 二档 | 500 元、600 元、700 元          | 81 元     |
| 三档 | 800 元、900 元                | 138 元    |
| 四档 | 1000、1100、1200、1300、1400 元 | 180 元    |
| 五档 | 1500、1600、1700、1800、1900 元 | 285 元    |
| 六档 | 2000 元以上                   | 402 元    |

## 二、先对号入座：你要办的是哪一种？

城乡居民养老保险缴费，常见就这四种情形：

- **当年正常缴费**：每年按时缴、享政府补贴（见上）；
- **情形① 补缴未缴年份**：之前有断缴、漏缴的年度，想把年限补齐；
- **情形② 子女资助（当年）**：子女想为参保的父母做当年的个人资助，充实个人账户；
- **情形③ 二次缴费（提档）**：往年已经按较低档次缴了，现在想再提高档次。

## 情形①：未缴年份，鄂汇办直接补缴

**适用**：存在断缴/未缴年度，希望补齐缴费年限。

**操作路径**：

1. 打开鄂汇办（APP 或 支付宝小程序）；
2. 进入养老缴费相关入口，选择需要补缴的年度；
3. 确认金额后支付，支持多种缴费等方式；
4. 补缴完成。

**提醒**：是否允许补缴、可补哪些年度，以当地经办机构最新口径为准，缴费前可查询个人权益单信息确认未缴年份是否与实际一致。

![](https://blogimg.52v6.com/2026/07/84dc504f52e41312a21c9b0baed21df3.webp)

## 情形②：子女资助（当年），两条线都能办

**适用**：子女希望为父母做当年度的个人资助。

这条有两条办理线，哪条方便走哪条：

- **线 A（村集体 / 窗口）**：向村集体或相关经办窗口提出集体补助申请，再通过银行 / 云闪付完成缴费；(部分地方权限已回收,参考线B
- **线 B（核定单）**：到乡镇开「个人资助核定单」，回到鄂汇办按核定单缴费。(**2026.7.20新增**)

两条线最终都能完成当年资助缴费，区别在于申请环节是走村集体/窗口在线下银行或者云闪付缴费，还是先开核定单再到线上鄂汇办缴费。

![](https://blogimg.52v6.com/2026/07/e85c4ddbc04abcd3ba09792dbb0ff3ba.webp)

## 情形③：往年已缴低档，二次缴费提档

**适用**：往年按较低档次缴了，现在经济宽裕想提高档次。

**操作路径**：

1. 到乡镇（人社 / 经办窗口）开「二次缴费核定单」；
2. 打开鄂汇办，按核定单上的金额缴费；
3. 二次缴费完成。

**提醒**：这类业务需要先有核定单，再在鄂汇办按单缴费，顺序别反了。

![](https://blogimg.52v6.com/2026/07/4147177912290107822ffcd3eb542114.webp)

## 三、渠道汇总：三个入口，功能互通

不管是正常缴费、补缴，还是按核定单缴费，以下三个渠道都能完成：

| 渠道          | 正常缴费 | 补缴 | 核定单缴费 |
| ----------- | ---- | -- | ----- |
| 鄂汇办 APP     | ✓    | ✓  | ✓     |
| 支付宝「鄂汇办」小程序 | ✓    | ✓  | ✓     |
| 电子税务局 APP   | ✓    | ✓  | ✓     |

简单记：**鄂汇办的两种形态（APP / 支付宝小程序）+ 电子税务局 APP**，三条路都能走通。

## 四、实操提醒

- 凡是涉及「核定单」的业务，都要先到乡镇办理，再回线上缴费；
- 缴费成功后一般即时出完税凭证可以保存，方便日后查询；
- 具体缴费档次、金额、可办年度，以当地最新政策为准；
- 帮长辈办理时，一般可以代办，缴费一般也可以用自己的手机代缴，也可以登录其账号操作查询个人权益单信息，省得老人家跑腿。

## 五、养老金怎么算：缴了之后每月能领多少？

很多人只关心"怎么缴"，其实"缴了将来能领多少"更关键。城乡居民养老金由两部分相加：

**月养老金总额 = 基础养老金（含年限增发） + 月个人账户养老金**

### 1. 基础养老金：基础标准 + 缴费年限增发

基础养老金由"基础标准"和"缴费年限增发"两部分构成，具体标准因地区而异（以下为示例/参考值，以当地公布为准）：

| 地区              | 基础养老金基数（元/月）     | 缴费年限增发规则                                                     |
| --------------- | ---------------- | ------------------------------------------------------------ |
| 🏙️ 武汉市（标准示例）   | 367              | ≤15 年部分：每满 1 年加发 2 元；超过 15 年部分：每满 1 年加发 3 元                  |
| 🏞️ 省内其他地区（参考值） | 默认 180（可按当地规定上浮） | ≤15 年：每满 1 年加发 1 元；16–25 年：每满 1 年加发 2 元；26 年及以上：每满 1 年加发 3 元 |

简单说：**缴得越久，基础养老金越多**——长缴多得，就是这个意思。

### 2. 个人账户养老金：总额 ÷ 139

**月个人账户养老金 = 个人账户总额 ÷ 139**

- 139 是 60 周岁领取对应的计发月数（国家统一标准）；
- 个人账户总额 = 个人缴费 + 政府补贴 + 集体补助（如有）+ 利息，历年累计。

### 3. 算一笔（武汉·最高档示例）

假设在武汉按最高档 9600 元/年，用三种方式充实个人账户（不计利息，仅作示意）：

- **补缴 15 年（无政府补贴）**：15 × 9600 = 144,000 元
- **今年按时缴费 1 年（享补贴 402）**：9600 + 402 = 10,002 元
- **个人资助 9600 元**（不增加缴费年限，仅入个人账户）：+ 9,600 元
- **个人账户总额 ≈ 144,000 + 10,002 + 9,600 = 163,602 元**
- **月个人账户养老金 ≈ 163,602 ÷ 139 ≈ 1,177 元**
- 缴费年限 = 15（补缴）+ 1（今年）= 16 年（个人资助不计入年限）；武汉年限增发 = 15×2 + 1×3 = 33 元
- **基础养老金 = 367 + 33 = 400 元**
- **月养老金总额 ≈ 400 + 1,177 = 1,577 元**

> 提示：以上为按示例标准的测算，实际领取以退休时当地公布的基础养老金标准、个人账户计息情况为准；补缴、资助、二次缴费计入个人账户后，同样参与"总额 ÷ 139"的计算。

### 4. 基础养老金还会逐年提高（以湖北为例）

城乡居民基础养老金不是一成不变的，国家会统一部署逐年上调。就湖北而言：

- **2026 年**：据往年节奏，湖北城乡居民基础养老金预计再提高 20 元/月，但**截至发稿暂未正式落实**，具体标准与落地时间请以官方公布为准；
- **2025 年**：上调于 **9 月**落实；
- **2024 年**：上调于 **11 月**落实。

无论当年几月落地，落实时通常会对**当年 7 月起的差额一次性补发**到账——即把上调前按旧标准少发的部分补给参保人，一般无需单独申请。

> 提示：上调幅度、落地时间、补发范围以当地人社部门 / 经办机构最新公布为准；本文所述年份节奏为参考，不作承诺。

## 结语

城乡养老这事儿，多缴一点，以后每月就多领一点；当年缴还能白白多拿一笔政府补贴。可以把这篇转给有需要的朋友或者家里的长辈，能少跑一趟是一趟。
